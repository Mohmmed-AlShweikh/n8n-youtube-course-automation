# أتمتة كورس يوتيوب بـ n8n

نظام أتمتة على n8n بيجهّز وبينشر **فيديو تعليمي قصير كل يوم** على يوتيوب: كتابة السكربت، تعليق صوتي عربي، ترجمة، رندر الفيديو، موافقة اختيارية من تيليجرام، النشر، والتسجيل، بدون أي مونتاج يدوي.

انبنى لتشغيل كورس متسلسل ("تعلّم أتمتة الذكاء الاصطناعي مع n8n من الصفر"، 30 درس)، وبتقدر تغيّر الموضوع واللغة والصوت والموعد.

## كيف يشتغل

1. **الجدولة**: تشغيل يومي حسب Cron (الافتراضي `0 11 * * *`).
2. **اختيار الدرس**: رقم الدرس بيتحسب من ورقة Log، فإذا فشل النشر بيعيد نفس الدرس ولا بيتخطاه.
3. **كتابة السكربت** بواسطة Gemini API على شكل مشاهد قصيرة.
4. **اختيار مقاطع** من Pixabay لكل مشهد.
5. **الرندر** بـ JSON2Video: صوت عربي + ترجمة تلقائية بصيغة 9:16.
6. **الموافقة (اختيارية)**: رسالة تيليجرام فيها زر "نشر" و"إلغاء"، والرد بيرجع داخل تيليجرام بدون ما يفتح متصفح.
7. **النشر** على يوتيوب، وتسجيل الدرس بـ Google Sheets، وإشعار "تم النشر".
8. **إشعار الأخطاء** على تيليجرام عند أي فشل.

## المميزات

- نشر يومي مجدول بدون تدخل.
- محرك كورس متسلسل مع منع تخطي الدروس.
- سكربتات بالذكاء الاصطناعي بطول محكوم (حوالي 35 إلى 45 ثانية).
- تعليق صوتي عربي وترجمة تلقائية.
- مقطع مختلف لكل مشهد قدر الإمكان.
- موافقة بزر من تيليجرام (نشر / إلغاء).
- إشعارات أخطاء فورية.
- التحكم بالخصوصية (`private` / `unlisted` / `public`) من node واحد.
- رابط الدرس السابق بوصف كل فيديو.
- سجل منظم لكل ما اننشر.

## محتويات المستودع

| المسار | الوصف |
|---|---|
| `workflows/youtube-course-main.json` | الـ workflow الرئيسي |
| `workflows/youtube-approval-handler.json` | بيستقبل ضغطة الأزرار وبينشر أو بيلغي |
| `workflows/youtube-error-notifier.json` | إشعار الفشل على تيليجرام |
| `templates/log.csv` | عناوين ورقة `Log` |
| `templates/pending.csv` | عناوين ورقة `Pending` |

تم حذف كل الـ Credentials والمعرّفات. لازم تضيف الخاصة فيك.

## المتطلبات والتركيب

الخطوات التفصيلية والجدول الكامل للـ Credentials موجودة بالنسخة الإنجليزية: [README.md](README.md).

باختصار:
1. اعمل Google Sheet فيه ورقتين `Log` و`Pending` بعناوين الملفات بمجلد `templates`.
2. اعمل Credentials: Gemini وPixabay وJSON2Video وGoogle Sheets وYouTube وTelegram (بوت **جديد** من @BotFather).
3. استورد كل ملف بـ workflow منفصل: الإشعارات، ثم الـ handler، ثم الرئيسي.
4. بدّل `YOUR_GOOGLE_SHEET_ID` و`YOUR_TELEGRAM_CHAT_ID`.
5. اربط Error workflow، وفعّل الـ handler ثم الرئيسي.
6. اضبط `privacy` و`requireApproval` بـ node اسمه `Config`.

## حدود معروفة

- JSON2Video بيحدد مدة الفيديو حسب الخطة (60 ثانية بالمجانية).
- مشاريع YouTube API غير المدققة ممكن تبقى الفيديوهات فيها خاصة.
- المقاطع عامة ما بتعرض واجهة n8n الحقيقية، وللدروس العملية الأفضل تسجيل شاشة.
- سكربتات الذكاء الاصطناعي ممكن فيها أخطاء معلوماتية، فراجع أول الفيديوهات وخلّي الموافقة شغالة.
- لازم تفصح عن المحتوى المصنّع بالذكاء الاصطناعي بحسب سياسات يوتيوب.
